# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public issue**.

Report it privately by email: **alban.mary1@gmail.com**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

I'll acknowledge your report within 24 hours and aim to release a fix within 2 days for critical issues.

## Scope

This policy covers the source code in this repository. It does not cover third-party dependencies (report those to their respective maintainers).

## Supported Versions

Only the latest version deployed at [albanmary.com](https://albanmary.com) is actively maintained.
